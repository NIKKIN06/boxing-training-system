# Запис про кодинговий агент

## Обраний інструмент

Antigravity Extension для Visual Studio Code.

## Клас інструменту

Інтегрований у середовище розробки кодинговий агент на основі штучного інтелекту.

## Спосіб доступу до репозиторію

Агент використовується через розширення Antigravity у Visual Studio Code та працює з файлами відкритого локального каталогу Git-репозиторію.

## Доступні операції

У межах наданих користувачем дозволів агент може:

- аналізувати структуру проєкту;
- читати файли репозиторію;
- пропонувати зміни до файлів;
- створювати та редагувати файли;
- допомагати з аналізом змін і підготовкою команд Git.

Усі зміни агента підлягають обов'язковому перегляду користувачем засобами Git перед створенням коміту.
