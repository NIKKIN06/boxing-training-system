# Запис про кодинговий агент

## Обраний інструмент

Antigravity Extension для Visual Studio Code.

## Клас інструменту

Інтегрований у середовище розробки кодинговий агент на основі штучного інтелекту.

## Спосіб доступу до репозиторію

Агент використовується через розширення Antigravity у Visual Studio Code та працює з файлами відкритого локального каталогу Git-репозиторію.

## Доступні операції

У межах наданих користувачем дозволів агент може:

- аналізувати структуру проєкту;
- читати файли репозиторію;
- пропонувати зміни до файлів;
- створювати та редагувати файли;
- допомагати з аналізом змін і підготовкою команд Git.

Усі зміни агента підлягають обов'язковому перегляду користувачем засобами Git перед створенням коміту.

## Зміна кодингового агента та його повноважень — 16.10.2026 (ЛР-3)

### Попередній агент
Antigravity Extension для Visual Studio Code. Використовувався в ЛР-1 та ЛР-2, зокрема для контрольної перевірки специфікації 28.09.2026.

### Новий агент
Claude Code (розширення для Visual Studio Code). Використовується починаючи з ЛР-3.

- Клас інструменту: кодинговий агент, інтегрований у середовище розробки.
- Доступ до репозиторію: через відкриту локальну папку репозиторію у VS Code.
- Операції: читання й редагування файлів проєкту, виконання команд у терміналі (git, gh) з підтвердженням власника.
- Постійні правила для агента зафіксовано в CLAUDE.md, технічні обмеження дозволів — у .claude/settings.json.

### Причина заміни
Зʼявився доступ до більш потужного та якіснішого інструменту.

### Повноваження агента
Попереднє правило (ЛР-1): агент не створює коміти.
Нове правило: агент може створювати коміти з позначкою [agent] лише для docs/plan/ та журналу сесії ЛР-3, після перегляду diff і підтвердження власником.
Залишаються за людиною: коміти gate:, зміни в spec/ без прямого дозволу, push, merge, рішення PLAN-GATE, валідація задуму.
Автор коміту в Git — власник; участь агента позначається [agent] та рядком Co-Authored-By.

### Статус попередніх артефактів
Артефакти ЛР-1 та ЛР-2, підготовлені за участі Antigravity, залишаються чинними.
Затверджена SRS v1.0 (коміт 533ee59) не переглядається у зв'язку зі зміною агента.
