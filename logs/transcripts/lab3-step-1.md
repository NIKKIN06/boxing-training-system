     План: мітки типів тікетів (gh label create)

     Context

     Для SDD-циклу проєкту потрібні мітки типів тікетів у GitHub-репозиторії.
     Користувач просив спершу показати команди, а не виконувати їх. Конвенцій
     щодо міток у репо немає (docs/git-workflow.md відсутній), тож кольори
     обрано довільно. Описи не довші за 100 символів (ліміт GitHub).

     Команди (виконувати з кореня репозиторію)

     gh label create "type:Specification" --color "1D76DB" --description
     "Формування та уточнення вимог SRS (REQ-F/REQ-NF) — еталон SDD-циклу"
     gh label create "type:Addendum"      --color "5319E7" --description
     "Доповнення до затвердженої SRS: уточнення чи зміна вимог після базової
     версії"
     gh label create "type:Test"          --color "FBCA04" --description "Тести
     та BDD-сценарії, виведені з критеріїв приймання AC-..."
     gh label create "type:Feature"       --color "0E8A16" --description
     "Реалізація функціональності за вимогами SRS з посиланням на REQ-ID"
     gh label create "type:Verification"  --color "C5DEF5" --description
     "Перевірка відповідності реалізації специфікації (чи правильно зроблено)"
     gh label create "type:Validation"    --color "BFD4F2" --description
     "Підтвердження, що продукт відповідає потребам користувача (чи те
     зроблено)"
     gh label create "type:Documentation" --color "0075CA" --description
     "Супровідна документація, звіти та матриця трасування вимог"
     gh label create "type:Gate"          --color "B60205" --description
     "Контрольна точка: не створює код чи тести, лише дозволяє або забороняє
     перехід"

     Якщо мітка вже існує — додати --force, щоб оновити колір та опис.

     Verification

     gh label list --search "type:" — має показати 8 міток з наведеними описами.
