# Журнал взаємодії з кодинговим агентом — ЛР-3

## Етап 1. Налаштування трекера — 16.10.2026
**Модель:** Claude Opus 5.5 (claude-opus-5-5), Claude Code у VS Code
**Запити:**
1. Виконати `git push`.
2. Підготувати команди `gh label create` для міток типів тікетів (type:Specification, type:Addendum, type:Test, type:Feature, type:Verification, type:Validation, type:Documentation, type:Gate) з коротким описом українською про роль у SDD-циклі; для type:Gate зазначити, що мітка не створює код чи тести, лише дозволяє або забороняє перехід. Спершу показати команди, не виконувати.

**Пропозиція агента та дії:**
- `git push` — агент спробував виконати, запуск команди відхилено; push не здійснено.
- Мітки — у режимі планування агент підготував 8 команд вигляду
  `gh label create "type:<Тип>" --color "<HEX>" --description "<опис>"`
  (кольори обрано довільно, бо конвенцій щодо міток у репозиторії немає; описи ≤ 100 символів). Після схвалення плану людиною агент виконав усі 8 команд і перевірив результат через `gh label list --search "type:"` — створено всі 8 міток.

**Повний діалог:** logs/transcripts/lab3-step-1.md
**Рішення людини:** Обрано GitHub Issues + Projects; статуси, поля й вигляди
налаштовано вручну. Описи міток type:* перевірено, прийнято без змін. Дефолтні мітки enhancement, documentation, good first issue, help wanted, accessibility архівовано, решту залишено (причини — docs/plan/tracker-setup.md). Чернетку tracker-setup.md підготовлено за допомогою Claude у чаті, звірено з фактичними налаштуваннями та відредаговано.
