# Інформаційна система планування та формування тренувань з боксу

Репозиторій містить артефакти SDD-проєкту інформаційної системи для автоматизації планування боксерських тренувань.

## Структура

- spec — описи задуму та специфікації;
- tests — тестові матеріали;
- src — програмний код;
- docs — документація;
- logs — журнали роботи та контрольні рішення.
