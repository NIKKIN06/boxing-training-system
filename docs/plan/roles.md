# Розподіл ролей людини й кодингового агента

| Тип тікета | Виконує | Роль людини |
| --- | --- | --- |
| Specification | Joint | Затверджує зміни специфікації, каталог і контрольні параметри |
| Addendum | Joint | Формулює рішення, затверджує адендум |
| Test | Agent | Переглядає тести на TEST-GATE до реалізації |
| Feature | Agent | Переглядає diff і результати тестів, приймає на IMPL-GATE |
| Verification | Joint | Аналізує результат перевірки, звіряє з SRS |
| Validation | Human | Перевіряє відповідність продукту задуму |
| Documentation | Agent | Переглядає та затверджує зміст |
| Gate | Human | Приймає рішення GO або REVISE |

Валідація задуму та рішення Gate агенту не делегуються.

Фактичний розподіл тікетів за полем Executor: Agent — 45, Joint — 15, Human — 11.
