## 3. Непрямі ланцюжки блокування

Для цих тікетів прямий зв'язок не потрібен: їх блокує ланцюжок до T-59. Перевірено автоматичним обходом графа залежностей із колонки «Залежить від» у `decomposition-draft.md` (60 тікетів; циклів не виявлено). Для кожної прямої залежності наведено найкоротший шлях до T-59.

| Тікет | Ланцюжки до T-59 |
|---|---|
| T-04 | T-04 → T-03 → T-59 |
| T-49 | T-49 → T-04 → T-03 → T-59; T-49 → T-32 → T-59; T-49 → T-39 → T-59 |
| T-51 | T-51 → T-34 → T-59; T-51 → T-50 → T-35 → T-59 |
| T-52 | T-52 → T-35 / T-40 / T-43 / T-45 / T-46 / T-48 → T-59 |
| T-53 | T-53 → T-09 → T-59; T-53 → кожен із T-30–T-35, T-38–T-48 → T-59 |
| T-54 | T-54 → T-50 → T-35 → T-59; T-54 → T-57 → T-59 |
| T-60 | T-60 → T-49 → T-32 → T-59; T-60 → T-50 → T-35 → T-59 |

T-50 сам від T-59 не залежить, бо його джерела не змінюються. Проте він блокується через екрани, що реалізують змінені вимоги (T-35, T-40, T-43, T-46, T-48). Тому T-51, T-54 і T-60 мають через T-50 додатковий шлях до T-59.
