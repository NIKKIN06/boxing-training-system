# Вимоги посиленого контролю

Критерій відбору: висока ціна відмови — можлива шкода здоров'ю користувача, тиха втрата або спотворення даних, порушення приватності чи хибна поведінка, яку користувач не може помітити сам.

| Вимога | Чому висока ціна відмови | Додатковий контроль |
| --- | --- | --- |
| REQ-F-001, CON-005 | Хибні межі навантаження в каталозі можуть зашкодити здоров'ю спортсмена; агент не може їх визначати | Затвердження каталогу людиною після консультації з експертами (T-56, T-03); верифікація на реальному каталозі (T-49) |
| REQ-F-007 | Помилка обчислення чи округлення часу тихо спотворює кожен план; користувач не перевіряє арифметику | Граничні приклади AC-F-007 (660 с, 5429 с, 5430 с) переглядаються людиною на TEST-GATE до реалізації |
| REQ-F-008 | Хибний допуск дає плани, що не відповідають цілі | Граничні тести на обох межах допуску включно, перегляд на TEST-GATE |
| REQ-F-006, REQ-F-009 | Недетермінований пошук, зависання або хибне «неможливо сформувати» | Тести властивостей з фіксованим зерном і підставленим годинником (D-11, D-13); окрема верифікація алгоритму |
| REQ-F-013 | Припинення без збереження може тихо змінити історію, аналітику чи збережений план | Тест, що припинення не змінює жодного з трьох; перегляд на TEST-GATE |
| REQ-F-014, D-20 | Зміни каталогу можуть спотворити історію завершених тренувань | Тест незалежності історії від каталогу (копії даних) |
| REQ-NF-001 | Основні функції недоступні без мережі | Прогін на Android у режимі польоту (T-50) |
| REQ-NF-004, D-02 | Витік даних через query-параметри посилань або мережеві запити | Моніторинг трафіку інструментом у режимі VPN на пристрої (наприклад, HTTP Toolkit) і через вкладку Network у Flutter DevTools (T-51; ADD-001 D-02) |
